# Zatwierdzone mody

Właściciel repozytorium dodaje tutaj pliki `.jar` zgodne z Minecraft Java 1.21.1 i Fabric. Launcher pobiera je do folderu gry przy starcie i podczas ręcznej aktualizacji.

Nie umieszczaj tu haseł, tokenów ani plików gry Minecraft. Repozytorium jest publiczne; dodawaj tylko mody, których licencje pozwalają na udostępnianie.
